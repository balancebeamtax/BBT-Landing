## FAQ section

### Does a tax extension mean I have more time to clean up the books?

No. The extension gives more time to file the return. The books still need to be reviewed and cleaned up before the return can be prepared.

### Which deadline applies to me?

It depends on the return being filed. Many Schedule C filers work toward October 15. Calendar-year partnerships and S corporations commonly work toward September 15. If you are not sure, review your prior-year return, extension confirmation, and entity structure with your preparer.

### Should I read the articles first or request a review?

If you are still learning what might be wrong, start with the article that matches your situation. If the deadline is approaching or your preparer is waiting on books, request a review.

### Can Balance Beam prepare the return too?

Balance Beam provides bookkeeping and tax preparation services. If cleanup is needed first, the cleanup scope and tax preparation scope should be separated clearly.
